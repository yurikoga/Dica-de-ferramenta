# Share Button Tooltip using HTML & CSS | Social Media Icons

Um projeto simples de **botão de compartilhamento com tooltip** usando HTML e CSS.

## ✨ Sobre

Este projeto demonstra como criar um **share button com ícones de redes sociais e tooltip**, ideal para sites modernos.

## 🛠️ Tecnologias

- HTML
- CSS

## 🎯 Funcionalidades

- Botão de compartilhamento
- Tooltip com ícones sociais
- Animação simples no hover

## 🚀 Como usar

1. Baixe ou clone o repositório  
2. Abra o arquivo `index.html` no navegador
